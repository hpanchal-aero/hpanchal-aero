## Why Aerospace

I've always been drawn to the boundary between what's possible and what hasn't been done yet. The SR-71 is one of the machines that shaped that — not because it reached Mach 3, but because doing so required solving aerodynamics, propulsion, heat transfer, materials, and structural problems that hadn't been solved together at that scale before.

My long-term interest is in the coupled physics that stand between today's sustained high-speed flight capability and the next step up — compressible flow and transition, aerothermal heating, thermal protection, structural response, and fluid–structure interaction.
